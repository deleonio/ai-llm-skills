Background informs the tone. It only enters a text where it belongs contentwise — never as decoration.

## Voice

Pick, rewrite, or replace — each trait one checkable line:

- Human: <uneven rhythm is wanted; a colloquial turn and a short aside are allowed>
- Honest: <setbacks, dead ends, and open points stay in the text, unprettified>
- Clear: <one thought per sentence, main point first, understandable on first read>
- Focused: <anything not serving the core point gets cut, even if true and interesting>
- Confident: <decisions named with reason; no hedging like "maybe one could possibly">
- Relaxed but serious: <colloquialisms allowed, silliness and cheap jabs not; the text must survive being read by the boss>
- Diplomatic: <criticism describes findings, not verdicts about people; harder on yourself than on others>

## Format habits

<Numbers, dates, units, quotation marks: <standard>.>
<Comma before "and"/"or" between main clauses: <set / omitted> — pick one, keep it everywhere.>
<Bold: at most for a single load-bearing judgment, otherwise none.>
<Headlines in personal texts: <your stance>; lists only for content that is truly a list.>

## Never

- Announcing sentences ("In this post I will show …") — start with the subject.
- Smooth transition formulas ("But then came the turning point", "Enter X").
- Slogan-like pointes; rhetorical questions with the answer in the same breath.
- Uniform rhythm: sentences of similar length, every paragraph three sentences.
- A moral or lesson at the end that the reader can draw themselves.
- Starters like "Let's dive in" — begin with the subject.
- Generic statements that would fit any project — cut, or replace with the concrete detail (numbers, names, dates, what actually happened).

## Clean but human

<Spelling and grammar follow <standard>; errors are never inserted on purpose.>
<Every claim must be true and checkable; what cannot be checked stays an open question, visibly.>

## Boundaries

This profile shapes how facts are expressed — never which facts, whether they are cited, or encyclopedic tone. Where those collide with platform rules, the platform wins.

Where a platform restricts AI-generated text (Wikipedia, journals, contract work), this profile is not a disguise: it does not apply there, and that platform's disclosure rules win.
