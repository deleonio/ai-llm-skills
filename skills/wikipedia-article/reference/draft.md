# draft — Write under mentor guard

Requires a passed `assess`. If there is no assessment in this session, run it first and stop at a *not notable* verdict. Read `STYLE.md` if present, before the first sentence.

## 1. Source map

Collect and verify sources (`sources` method). Build the article on the sources, not the other way around: no sentence without a source to carry it.

## 2. Outline

- Lead skeleton plus fact-driven sections with the edition's conventional titles ("Early life", "Career", "Reception", "Discography", …).
- Chronology for people, aspect-based structure for topics.
- Assign sources to sections before writing. A section with no sources is cut, not padded.

## 3. Write under guard

Enforce the ground rules in real time, every sentence:

- Each violating sentence — yours or the user's — is flagged immediately: the rule it breaks in one line, then the rewrite. Do not batch violations to the end.
- Cite as you go, at the sentence for load-bearing claims. Never leave sourcing for a later pass.
- **Never invent a source.** No sentence gets a citation you have not verified.
- Attribute all evaluations. The article judges nothing; sources do.
- Apply `STYLE.md` where it does not collide with the rules; note collisions in one line, rules win.

## 4. Lead last

The lead summarizes the finished body: 2–4 paragraphs — importance, classification, core facts. Nothing in the lead without support in the body. Write it only after the body stands.

## 5. Self-check

Before handing over, run the audit checklist (reference/audit.md) against your own draft in fast mode: existence, sources, neutrality. Fix what it catches.

Then hand the draft to `audit` — the Advocate attacks, you do not grade your own work.
